# SAP-Style ABAP Mapping

This repo remains vendor-neutral, but includes one ABAP-style layer to show familiarity with SAP enterprise application patterns.

## ABAP Artifact

`abap_layer/z_epo_readiness_check.abap`

## What It Demonstrates

- Purchase-order readiness validation
- Vendor and inventory status checks
- Shipment exception handling
- Go-live blocking logic
- SAP-style report structure
- ABAP internal-table processing
- Enterprise implementation governance

## Why This Matters

SAP application engineering roles often require understanding business workflows, validation logic, and ABAP-style implementation patterns.

This layer connects the Python enterprise process engine to SAP-style development without turning the whole repo into an SAP-only project.
